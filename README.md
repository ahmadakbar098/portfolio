# Personal Developer Portfolio — Adhel Fahri Anggara

Repositori resmi portofolio web personal berbasis arsitektur statis modern. Dirancang untuk menyajikan profil profesional, rekam jejak teknis, dan portofolio proyek rekayasa perangkat lunak dengan performa tinggi, skor aksesibilitas optimal, dan antarmuka minimalis responsif.

## 🚀 Fitur Utama

- **Zero-Latency Static Architecture:** Waktu muat instan tanpa dependensi framework runtime yang berat.
- **Mobile-First Responsive Layout:** Optimal diakses melalui smartphone, tablet, maupun layar desktop.
- **Minimalist Professional UI:** Mengadopsi palet warna berstandar rasio kontras WCAG AAA dan tipografi modern (*Plus Jakarta Sans*).
- **Structured Showcase:** Format kartu proyek berbasis *problem-solution-stack* dengan tautan langsung ke demo dan repositori.
- **Direct Conversion Flow:** Akses unduh CV dengan satu klik dan integrasi tautan kontak langsung.

## 🛠️ Tech Stack

- **Markup & Struktur:** HTML5 Semantic
- **Styling & Layout:** Tailwind CSS
- **Interaktivitas:** Vanilla JavaScript (ES6+)
- **Desain Ikon:** Lucide Icons & Custom SVG
